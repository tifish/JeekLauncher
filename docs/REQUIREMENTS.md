# JeekLauncher 功能需求

## 产品定位

JeekLauncher 是 Windows 键盘优先应用启动器。程序常驻系统托盘，用户通过全局快捷键呼出搜索框，用少量字符定位并启动应用。

## 功能需求

### 启动器

- 全局热键显示或隐藏启动器。
- 单实例运行；再次启动时唤起已有实例。
- 支持键盘选择、回车启动、Esc 关闭和窗口失焦隐藏。

### 应用发现

- 扫描所有用户和当前用户开始菜单中的 `.lnk`、`.url` 快捷方式。
- 枚举可直接启动的 MSIX/Microsoft Store 应用。
- 支持配置额外扫描目录，并自动监控增删和重命名。
- 合并重复条目，过滤不可启动的系统杂项。

### 搜索与排序

- 支持名称、英文首字母、中文拼音首字母和全拼。
- 支持前缀、子串和子序列匹配，不要求输入完整名称。
- 首字母命中优先；用户曾用查询绑定的快捷词始终优先。
- 同等匹配条件下按启动次数排序；空查询显示常用应用。

### 记忆与配置

- 启动后保存“查询词 → 应用”的快捷词映射。
- 快捷方式暂时消失时保留映射，重装后可继续使用。
- 支持语言、主题、热键、开机启动、更新策略和配置存储位置设置，并即时生效。
- 可漫游偏好与本机扫描目录、使用次数分开保存。

### 更新与诊断

- 从 GitHub Releases 检查和安装更新，支持镜像切换。
- 提供无界面自检，用于验证搜索、监控、开机启动和语言功能。

## 核心机制

扫描器在后台把不同来源统一为应用条目并建立索引；文件系统事件经过短暂合并后触发重扫。搜索引擎为每个候选项计算匹配等级，再叠加快捷词和使用次数形成稳定排序。配置由统一存储层管理，便携模式由程序目录中的 `Config` 文件夹优先决定。UI 只负责交互，扫描、搜索、配置和更新逻辑位于 `Services`。
